# Axiom-Inference-Engine
Package(er) and loader scripts and examples for .axim model packages.

This repository contains the basic scripts required to know how .axim files work, and how to improve them, as well as a super basic webUI for inferring models.



#### As of 26/6/2026 this repository is basically made just for my axiom lineup of models. https://huggingface.co/Strawbercar/Axiom-V1-Base
